Boot animation: the Gemini animation of the Pixel 10 (https://github.com/docbt/GeminiBootAnimation, MIT, Copyright (c) 2026 docbt), fitted to the 1200x1920 panel.
Download `product/media/bootanimation.zip` from that repository, run `make_gemini_fit.py ORIGINAL.zip OUT.zip`, and copy OUT.zip to `/system/product/media/bootanimation.zip` (stored zip, 13 MB).
The Android 16 port repository ships the already fitted file.
